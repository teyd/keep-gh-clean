# keep-gh-clean

See all your GitHub repositories in one table, then change visibility, archive or delete them in one click or in bulk.

**→ [teyd.github.io/keep-gh-clean](https://teyd.github.io/keep-gh-clean/)**

- Lists your own repos plus org repos you're an admin of, with visibility, language, stars, forks, size, and created / last push / updated dates
- Search, filter (owner, visibility, archived, fork, language) and sort on any column
- Detail drawer: commit count, recent commits, top contributors, topics, license, open issues and PRs
- One-click public ⇄ private and archive ⇄ unarchive with undo; delete requires typing the repo name
- Bulk actions on selected repos, with progress and a per-repo failure summary

## How it works

It's a static site with no backend. You paste a GitHub token and the browser talks to `api.github.com` directly.

- The token is kept in `sessionStorage` (or `localStorage` if you tick "Remember on this device") and is never sent anywhere else.
- Production builds ship a Content-Security-Policy that only allows network requests to `api.github.com`.
- There is no analytics or tracking.

## Token

[Create a classic token](https://github.com/settings/tokens/new?scopes=repo,delete_repo,read:org&description=keep-gh-clean) with these scopes:

| Scope | Needed for |
| --- | --- |
| `repo` | Private repos, changing visibility, archiving |
| `delete_repo` | Deleting (leave it out to make deleting impossible) |
| `read:org` | Listing repos in your organisations |

Fine-grained tokens also work (Repository permissions → Administration: read and write, Metadata: read), but each one is limited to a single owner. The app can't read a fine-grained token's permissions up front, so every button stays enabled and GitHub rejects anything the token can't do.

## Development

Tools are managed with [mise](https://mise.jdx.dev) (Node 24, pnpm 12). Build config is managed with [varlock](https://varlock.dev).

```sh
mise install
pnpm install
pnpm dev
```

| Command | |
| --- | --- |
| `pnpm dev` | Dev server |
| `pnpm build` | Type-check (TypeScript 7) and build to `dist/` |
| `pnpm typecheck` | Type-check only |
| `pnpm preview` | Serve the production build |

### Config

Build-time settings live in [`.env.schema`](.env.schema). None of them are secret. Override them in `.env.local` or the environment:

| Variable | Default | |
| --- | --- | --- |
| `BASE_PATH` | `/` | Path the site is served from. Set automatically in CI. |
| `SOURCE_URL` | this repo | "Source" link in the footer |

`src/env.d.ts` is generated by varlock from the schema and is committed, so type-checking works before Vite runs.

## Deploy

Every push to `main` deploys to GitHub Pages through [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). Enable it once under **Settings → Pages → Source: GitHub Actions**.
